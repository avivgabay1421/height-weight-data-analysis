# Height and Weight Data Analysis

This project performs data analysis using Python, NumPy, Pandas, and Matplotlib.

## Overview

- Processed numerical data using NumPy
- Cleaned and analyzed a height and weight dataset
- Converted measurement units from inches to centimeters and pounds to kilograms
- Identified and handled anomalies in the data
- Visualized data using histograms

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib

## How to Run

1. Make sure the following files are in the same folder:
 * data_q1.csv
 * height_and_weight.csv
   
2. Run the script: python height_weight_analysis.py

## Output

- Histograms of grouped means
- Height distribution in centimeters
- Weight distribution in kilograms
